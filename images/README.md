## Screenshot Security Checklist

公开截图前检查：

- 不包含密码
- 不包含 API Key
- 不包含 Session / Cookie
- 不包含 Authorization Header
- 不包含真实 `.env`
- 不包含数据库密码
- 不包含 Redis / RabbitMQ 密码
- 不包含 HMAC Secret
- 不包含 SSH Key
- 不包含个人敏感信息
- 不展示包含凭证的完整请求 Header
- 不展示包含凭证的 Docker environment

README 最终只需要展示最有代表性的 3～4 张截图。
